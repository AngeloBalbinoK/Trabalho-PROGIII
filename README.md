# Sistema de Gestão de Missões de Resgate

Sistema desenvolvido em Java para simular o gerenciamento de uma frota de veículos de emergência e o despacho de chamados de resgate.

## Objetivo

O projeto tem como objetivo aplicar conceitos de Programação Orientada a Objetos (POO), organização em camadas e persistência de dados em Java.

## Funcionalidades

- Cadastro de ambulâncias.
- Cadastro de motos de resgate.
- Registro de chamados de emergência.
- Despacho de veículos para ocorrências.
- Controle de disponibilidade dos veículos.
- Validação de dados.
- Histórico de chamados.
- Persistência de dados em arquivo binário.

## Tecnologias utilizadas

- java version "25.0.4" 2026-07-21 LTS
- Programação Orientada a Objetos (POO)
- Java Serialization
- Git
- GitHub
